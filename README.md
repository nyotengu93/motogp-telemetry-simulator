# MotoGP Telemetry Simulator

A Python desktop application built with Tkinter that simulates real-time telemetry data for an Aprilia RS-GP26 running on the Lusail International Circuit.

## Features
- **Real-Time Data Simulation:** Speed, RPM, gear shifting, lean angles, fuel consumption, and sector times.
- **Session Control:** Start, pause, reset, and save session progress.
- **Data Persistence:** Save and reload telemetry sessions using JSON files.
- **Modular OOP Architecture:** Clean division between motorcycle dynamics, circuit physics, and GUI layers.

## Tech Stack
- **Language:** Python 3
- **GUI:** Tkinter
- **Data Format:** JSON
